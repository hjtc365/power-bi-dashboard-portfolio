# Campaign Performance Dashboard

Welcome to the Campaign Performance Dashboard! This folder contains all assets, data, documentation, and project files for the Power BI campaign performance solution.

## Folder Structure

- [assets/](assets/) — Custom Power BI themes and images
- [datasets/](datasets/) — Sample data and data dictionary
- [docs/](docs/) — Documentation on Power Query and data modeling
- [pbip/](pbip/) — Power BI Project files (recommended for version control)
- [pbix/](pbix/) — Power BI Desktop files
